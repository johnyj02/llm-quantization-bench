+# Supplementary data: item ordering and scoring in quantized model evaluation
+
+This archive accompanies the paper *Reproducibility Failures in Quantized Model Evaluation:
+Item Ordering Moves 4-Bit Accuracy and Leaves bf16 Exactly Unchanged*. It holds every model
+generation the paper's numbers are computed from, the order-invariance probe, and the human
+annotation record. Every record keeps the full generated text and the fields that cannot be
+reconstructed later, so any answer extractor can be re-run on it without a GPU.
+
+```
+corpus/<run_id>/<model>__<precision>/<task>[__<subtask>]__<prompt>__<budget>.jsonl
+determinism/l40s/        probe passes and per-cell analyses, NVIDIA L40S (SM 8.9)
+determinism/a10g/        second-GPU replication, NVIDIA A10G (SM 8.6)
+determinism/reports/     the three job reports the paper's ordering tables are built from
+annotation/              rubric, blinded sample, both annotators' labels, adjudication
+order_invariance_probe.py
+MANIFEST.json            record counts and SHA-256 of every file
+```
+
+Unpack with `tar -xJf <archive>.tar.xz`.
+

+## Record fields (schema 1.5.0)
+
+One JSON object per line. The join key is
+`(run_id, cell_id, task, subtask, item_id, budget_level, prompt_variant, sample_idx, repeat_idx)`.
+
+| field | meaning |
+|---|---|
+| `cell_id`, `model_repo`, `model_revision` | model and precision; revisions are commit SHAs, not tags. For GPTQ and AWQ, `model_repo` is the path of our quantized checkpoint inside the serving container; the base model is the first part of `cell_id` and the recipe is `quant_config_hash` |
+| `quant_method`, `bits`, `quant_config_hash` | quantization recipe; the hash identifies the exact calibration recipe |
+| `task`, `subtask`, `item_id`, `gold` | benchmark item and its reference answer |
+| `prompt_text`, `prompt_sha256`, `n_prompt_tokens` | the fully rendered prompt as served |
+| `prompt_variant`, `template_level`, `scoring_mode` | few-shot CoT or zero-shot; chat or raw template; `generate` or `loglikelihood` |
+| `budget_level`, `max_gen_toks` | generation budget (1x, 2x, 4x) and its token cap |
+| `generation_text` | the FULL output, never truncated for storage |
+| `finish_reason`, `n_gen_tokens` | why generation stopped (`stop` or `length`) and how many tokens it produced |
+| `until`, `until_applied` | the stop strings, and whether they were applied at `generation` (the engine halted there) or at `scoring` (the full output is kept and the scorer cuts it) |
+| `stop_reason`, `stop_string_hit`, `n_gen_tokens_scored` | which string ended the scored prefix, and that prefix's length in tokens |
+| `option_logprobs` | log-likelihood mode only: per-option log-probability and token count |
+| `decoding`, `seed`, `sample_idx`, `repeat_idx` | greedy throughout; `repeat_idx=1` is a second generation in the same job |
+| `engine`, `batch_invariant`, `max_num_seqs`, `disabled_kernels` | serving configuration (vLLM 0.26.0, batch-invariant mode on, `max_num_seqs=32`) |
+| `gpu`, `cuda`, `driver`, `env_hash`, `invocation_id`, `wall_ms` | hardware, and which engine load produced the record |
+
+Under `until_applied == "scoring"`, `finish_reason` and `n_gen_tokens` describe the full
+output; the scored answer is the prefix up to `stop_string_hit`.
+
+## Determinism probe data
+
+Each `raw_*.json` holds the probe passes for one cell: `passes[k]` has `ordering_seed`,
+`outputs` (item id to generated text) and `seconds`. The probe stores text only, not
+`finish_reason` or token counts. The file name encodes model, precision, served batch size
+(`at32`), repeats, the ordering count (`ord10x` for the ten-ordering runs), a decoding
+fingerprint (`dec…`), and `fallback` when the Marlin and Machete kernels were disabled.
+A cell file without the `raw_` prefix is that cell's analysis. `determinism/index.json`
+maps every raw file to the report and cell that use it, matched by a hash of its outputs;
+files no report uses were measured under an earlier configuration and are superseded.
+
+## The probe
+
+`order_invariance_probe.py` runs the same prompts in several orderings inside one vLLM
+engine and checks whether each output is byte-identical across orderings. It runs ordering
+0 twice first, so ordering effects are separated from run-to-run nondeterminism. It accepts
+corpus records directly:
+
+```
+VLLM_BATCH_INVARIANT=1 python order_invariance_probe.py \
+    --model Qwen/Qwen2.5-3B-Instruct --prompts prompts.jsonl --max-num-seqs 32
+```
+
+It exits 0 if the outputs are order-invariant and 1 if not. It needs a GPU and vLLM.
+
+## Annotation
+
+`rubric.md` is the decision procedure both annotators applied. `sample_key.json` maps each
+blinded annotation id to its corpus record (`run_id`, `cell_id`, `item_id`, ...).
+`to_annotate_A*.json` are exactly what each annotator saw, in their order;
+`labels_A*.jsonl` are their labels; `adjudicated.json` records how the disagreements were
+resolved and the rubric clause that decided each.

+#!/usr/bin/env python3
+"""Order-invariance probe: does item ORDER change what your engine generates?
+
+Runs the same prompts in several orderings inside ONE vLLM engine and checks whether
+every item's output is byte-identical across orderings. Ordering 0 is run twice first,
+so a non-zero result can be told apart from plain run-to-run nondeterminism.
+
+    VLLM_BATCH_INVARIANT=1 python order_invariance_probe.py \\
+        --model Qwen/Qwen2.5-3B-Instruct --prompts prompts.jsonl --max-num-seqs 32
+
+`prompts.jsonl` holds one object per line, either {"id": ..., "prompt": ...} or a record
+from the released corpus ({"item_id": ..., "prompt_text": ...}). Prompts must be FULLY
+RENDERED (chat template already applied); they are tokenized without adding special
+tokens, so a template that already emits BOS is not given a second one.
+
+Exit code 0 means order-invariant, 1 means at least one item changed with the ordering.
+"""
+
+from __future__ import annotations
+
+import argparse
+import json
+import os
+import random
+import sys
+
+# The ten orderings used in the paper. Seed 0 is the file's own order.
+PAPER_SEEDS = (0, 20260827, 20260828, 20260829, 20260830, 20260831,
+               20260901, 20260902, 20260903, 20260904)
+
+
+# Every sampling field pinned, as in the paper, including ones inert under greedy decoding.
+DECODING = {"temperature": 0.0, "top_p": 1.0, "top_k": -1, "repetition_penalty": 1.0,
+            "presence_penalty": 0.0, "frequency_penalty": 0.0}
+ENGINE_ENV = {"VLLM_BATCH_INVARIANT": "1", "VLLM_ENABLE_V1_MULTIPROCESSING": "0",
+              "VLLM_USE_FLASHINFER_SAMPLER": "0", "VLLM_ATTENTION_BACKEND": "FLASH_ATTN"}
+
+
+def load_prompts(path: str) -> list[tuple[str, str]]:
+    items = []
+    with open(path) as handle:
+        for line in handle:
+            if line.strip():
+                r = json.loads(line)
+                items.append((str(r.get("id", r.get("item_id"))),
+                              r.get("prompt", r.get("prompt_text"))))
+    if len({i for i, _ in items}) != len(items):
+        sys.exit("item ids must be unique")
+    return items
+
+
+def differing(passes: list[dict[str, str]]) -> list[str]:
+    """Items whose text is not byte-identical in every pass (a missing output counts)."""
+    ids = set().union(*passes)
+    return sorted(i for i in ids if len({p.get(i) for p in passes}) > 1)
+
+
+def main() -> int:
+    ap = argparse.ArgumentParser(description="Does item order change what vLLM generates?")
+    ap.add_argument("--model", required=True)
+    ap.add_argument("--revision")
+    ap.add_argument("--quantization", help="passed to vLLM, e.g. bitsandbytes")
+    ap.add_argument("--prompts", required=True)
+    ap.add_argument("--max-num-seqs", type=int, default=32)
+    ap.add_argument("--max-tokens", type=int, default=256)
+    ap.add_argument("--stop", action="append", default=None, help="repeatable")
+    ap.add_argument("--orderings", type=int, default=len(PAPER_SEEDS),
+                    help=f"how many of the paper's {len(PAPER_SEEDS)} seeds to use")
+    ap.add_argument("--dtype", default="bfloat16")
+    ap.add_argument("--allow-without-batch-invariance", action="store_true",
+                    help="run even if VLLM_BATCH_INVARIANT is not 1 (recorded in the report)")
+    ap.add_argument("--out", help="write the JSON report here as well")
+    args = ap.parse_args()
+
+    # The paper's serving environment. Set before vLLM is imported, because it reads them then.
+    # The FlashInfer sampler is a CUDA path that batch-invariant mode does not cover.
+    for key, value in ENGINE_ENV.items():
+        os.environ.setdefault(key, value)
+    if os.environ.get("VLLM_BATCH_INVARIANT") != "1" and not args.allow_without_batch_invariance:
+        sys.exit("VLLM_BATCH_INVARIANT is not 1. The paper measures with it on; pass "
+                 "--allow-without-batch-invariance to measure without it.")
+
+    from vllm import LLM, SamplingParams, TokensPrompt, __version__  # noqa: PLC0415
+
+    items = load_prompts(args.prompts)
+    # Tensor parallelism above one breaks batch invariance, and prefix caching makes an
+    # item's computation depend on what ran before it, so both are pinned here.
+    # `generation_config="vllm"` stops vLLM filling unset sampling fields from the model's own
+    # generation_config.json: Qwen2.5-3B-Instruct ships repetition_penalty 1.05, which changes
+    # greedy output because it rescales logits before the argmax.
+    llm = LLM(model=args.model, revision=args.revision, quantization=args.quantization,
+              dtype=args.dtype, tensor_parallel_size=1, enable_prefix_caching=False,
+              max_model_len=8192, max_num_seqs=args.max_num_seqs, seed=0,
+              async_scheduling=False, generation_config="vllm",
+              kernel_config={"enable_flashinfer_autotune": False})
+    tok = llm.get_tokenizer()
+    ids = {i: tok(text, add_special_tokens=False)["input_ids"] for i, text in items}
+    params = SamplingParams(**DECODING, max_tokens=args.max_tokens, stop=args.stop, seed=0)
+
+    def run(seed: int) -> dict[str, str]:
+        order = [i for i, _ in items]
+        if seed:
+            random.Random(seed).shuffle(order)
+        outs = llm.generate([TokensPrompt(prompt_token_ids=ids[i]) for i in order], params,
+                            use_tqdm=False)
+        return {i: o.outputs[0].text for i, o in zip(order, outs, strict=True)}
+
+    seeds = PAPER_SEEDS[: max(2, args.orderings)]
+    repeat = [run(0), run(0)]
+    by_order = [repeat[0]] + [run(s) for s in seeds[1:]]
+
+    rep, order = differing(repeat), differing(by_order)
+    report = {
+        "model": args.model, "revision": args.revision, "quantization": args.quantization,
+        "vllm": __version__,
+        "engine_env": {k: os.environ.get(k) for k in ENGINE_ENV}, "dtype": args.dtype,
+        "decoding": DECODING, "stop": args.stop,
+        "max_num_seqs": args.max_num_seqs, "max_tokens": args.max_tokens,
+        "orderings": list(seeds), "n_items": len(items),
+        "repeat_differing": len(rep), "order_differing": len(order),
+        "order_divergence": len(order) / len(items) if items else 0.0,
+        "examples": order[:5],
+    }
+    text = json.dumps(report, indent=2)
+    print(text)
+    if args.out:
+        with open(args.out, "w") as handle:
+            handle.write(text + "\n")
+    if rep:
+        print(f"\nNOTE: {len(rep)} items differ between two runs in the SAME order, so the "
+              "engine is not deterministic even before ordering is varied.", file=sys.stderr)
+    print("\nORDER-INVARIANT" if not order else
+          f"\nNOT ORDER-INVARIANT: {len(order)} of {len(items)} items changed with ordering",
+          file=sys.stderr)
+    return 0 if not order else 1
+
+
+if __name__ == "__main__":
+    raise SystemExit(main())

+def write_tar(counts: dict, determinism: dict) -> Path:
+    files = sorted(f for f in STAGE.rglob("*") if f.is_file())
+    manifest = {"records": counts, "determinism": determinism, "files": {
+        str(f.relative_to(STAGE)): hashlib.sha256(f.read_bytes()).hexdigest() for f in files}}
+    (STAGE / "MANIFEST.json").write_text(json.dumps(manifest, indent=2))
+    files.append(STAGE / "MANIFEST.json")
+
+    # Corpus files grouped by task file name across cells, so the same prompts sit close
+    # together and the compressor's window can see the repeats.
+    def order(f: Path):
+        rel = f.relative_to(STAGE)
+        return (0, rel.parts[1], rel.name, str(rel)) if rel.parts[0] == "corpus" else (1, str(rel))
+
+    tar_path = OUT / f"{NAME}.tar"
+    with tarfile.open(tar_path, "w", format=tarfile.PAX_FORMAT) as tar:
+        for f in sorted(files, key=order):
+            info = tar.gettarinfo(str(f), arcname=f"{NAME}/{f.relative_to(STAGE)}")
+            # The header would otherwise carry the builder's user name and uid.
+            info.uid = info.gid = 0
+            info.uname = info.gname = ""
+            info.mtime = 1792108800   # 2026-10-16, fixed so rebuilds are byte-identical
+            info.pax_headers = {}
+            with f.open("rb") as handle:
+                tar.addfile(info, handle)
+    with tarfile.open(tar_path) as tar:
+        bad = [m.name for m in tar.getmembers() if m.uname or m.gname or m.uid or m.gid]
+    if bad:
+        raise SystemExit(f"tar headers still carry an owner: {bad[:3]}")
+    return tar_path
+

+def main() -> int:
+    shutil.rmtree(STAGE, ignore_errors=True)
+    STAGE.mkdir(parents=True)
+    counts = stage_corpus()
+    determinism = stage_determinism()
+    stage_annotation()
+    for name in ("README.md", "order_invariance_probe.py"):
+        shutil.copy2(REPO / "release" / name, STAGE / name)
+    deny_scan()
+    tar_path = write_tar(counts, determinism)
+    print(f"  tar: {tar_path.stat().st_size / 1e6:,.0f} MB uncompressed")
+
+    # xz at its strongest preset, single-threaded (threads split the input and cost ratio),
+    # with a 256 MiB window so prompts repeated across cells and runs are matched.
+    xz = OUT / f"{NAME}.tar.xz"
+    xz.unlink(missing_ok=True)
+    subprocess.run(["xz", "-T1", "-k", "--format=xz", "--lzma2=preset=9e,dict=256MiB",
+                    str(tar_path)], check=True)
+    subprocess.run(["xz", "-t", str(xz)], check=True)
+    tar_path.unlink()
+    digest = hashlib.sha256(xz.read_bytes()).hexdigest()
+    (OUT / f"{NAME}.tar.xz.sha256").write_text(f"{digest}  {xz.name}\n")
+    print(f"  wrote {xz.relative_to(REPO)}  {xz.stat().st_size / 1e6:.1f} MB  sha256 {digest[:16]}")
+    shutil.rmtree(STAGE)
+    return 0

+    raise SystemExit(main())
