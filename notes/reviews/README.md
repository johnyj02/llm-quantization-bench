# Reviewer findings — raw answers, unabridged

One file per `./ask-reviewer` call, saved whole. Same discipline as
`notes/planner-answers/`, and for the same reason: a `tail -60` once truncated a planner
ruling and lost two of its points, so the raw text is kept and read from the file.

**Naming:** `<date>-<short-subject>.txt`.

For each review, record underneath what was **acted on** and what was **declined, with the
reason** — a finding dismissed without a recorded reason is one that gets re-raised every
time the reviewer's memory is refreshed.
